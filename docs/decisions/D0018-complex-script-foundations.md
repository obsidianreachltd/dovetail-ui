# D0018 — Complex scripts: the full bidirectional algorithm, paragraph direction, one caret

| Field | Value |
|---|---|
| ID | D0018 |
| Status | Accepted |
| Date | 2026-11-23 |

## Context

M13 adds Arabic and text that mixes right-to-left and left-to-right on one line. Three choices shape the work:

- how much of the Unicode bidirectional algorithm (UAX #9) to build;
- which way a paragraph runs, and where it sits in its box;
- how the caret is shown where the direction changes.

## Decision

- **The whole bidirectional algorithm is built:** explicit embeddings, overrides and isolates (X1–X10), weak and neutral types (W1–W7, N0–N2, with bracket pairs), implicit levels (I1–I2), and reordering on a line (L1–L2). It is checked against every case in Unicode's `BidiTest.txt` and `BidiCharacterTest.txt`. The Unicode data it needs is generated by `tools/ucd-gen`, as D0014 says.
- **A paragraph takes its direction from its first strong letter** (rules P2 and P3). Text whose paragraph runs right to left lines up on the right of its box. A setting to force a direction is left for later.
- **There is one caret.** Where the direction changes, it goes next to the character before it in the text, as current Windows, macOS and browsers show it. The arrow keys move it in visual order: Left always moves it left on the screen.

## Consequences

- Text with explicit direction characters, isolates and brackets is shown as Unicode says, so nothing has to be added to the algorithm later.
- Labels and text fields in Arabic line up as Arabic readers expect, without the application doing anything.
- With one caret, the side a new character goes on at a direction boundary is not always shown. This is what users of other systems are used to.

## Alternatives considered

- **Only implicit levels**, without explicit characters or bracket pairs: smaller, but text that has them is shown wrongly.
- **Always left to right paragraphs:** simpler, but a mainly Arabic label or field reads oddly.
- **A split caret**, with half a caret for each direction: clearer about where typing goes, but rarely seen now.
