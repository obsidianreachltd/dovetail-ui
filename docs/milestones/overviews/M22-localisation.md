# M22 — Localisation

## Summary

Let applications speak their users' languages: translated text with plurals and placeholders, numbers and dates in the user's format, and the layout mirrored for right-to-left languages.

## Why it matters

- **What exists:** text in any script is shown well. [M13](M13-complex-scripts.md) shapes Arabic and text that mixes directions, and M06 picks fonts for a text's language. But every string in a control, such as "OK", "Cancel" and "Search commands", is in English, and numbers are written one way.
- **What applications need:** their own text translated, numbers and dates written as their users expect, and a right-to-left layout for Arabic and Hebrew.
- **Doing it once:** if every application solves this itself, controls cannot follow along. The framework's own strings must be translatable too.
- **Dependencies:** the data for formats and plurals comes from the Unicode CLDR. Under [D0002](../../decisions/D0002-build-own-stack.md), how it is used needs a decision, as [D0014](../../decisions/D0014-unicode-data.md) did for the UCD.

## What it includes

- **The user's locale:** read from the system, changeable while the application runs, and passed down the tree like the theme.
- **Translated text:**
  - messages with placeholders and plural forms, looked up by key;
  - in plain text files, one for each language, kept by the application;
  - a fallback language when a message is missing, and a warning in development builds;
  - checking at build time that every message used exists.
- **Dovetail's own strings** in controls, commands, docking and documents, made translatable, with English and at least one other language.
- **Formats:** numbers, percentages, dates and times in the locale's way. `NumberField` reads and writes numbers in it.
- **Mirroring:** a right-to-left locale mirrors rows, alignment, scrollbars, arrows and icons that point.
- **Data:** CLDR data for a chosen set of locales, generated by a tool in `tools/`, as the UCD tables are.
- **An example** shown in several languages, one right to left, with a `--self-test`.

## What it leaves out

- Translating applications for them, or a tool for translators.
- Calendars other than the Gregorian one.
- Collation: sorting text in each language's order.

## Done when

1. An application's messages, with placeholders and plurals, show in the user's language, with a fallback when a message is missing.
2. Changing the locale while the application runs changes its text and formats.
3. Numbers and dates show in the locale's format, and `NumberField` reads numbers typed in it.
4. With a right-to-left locale, rows, alignment, scrollbars and pointing icons are mirrored.
5. Every string in Dovetail's controls is translatable, and a test fails if a new one is not.
6. The example's self-test checks each of its languages.
