# Mxx report — Milestone name

| Field | Value |
|---|---|
| ID | Mxx |
| Finished on | YYYY-MM-DD |
| Commit or tag | `abc1234` or `vX.Y.Z` |
| Plan | [Mxx plan](../plans/Mxx-slug.md) |

## Summary

Two or three sentences: what was built and whether every criterion was met.

## What was delivered

- One line per crate, feature, example or tool that now exists.

## Results

One row per "Done when" criterion, in the same order as the overview.

| # | Criterion | Result | Evidence |
|---|---|---|---|
| 1 | Short form of the criterion | Met / Not met | Test name, CI run, measurement or note |

## Changes from the plan

- Each step that was added, dropped or done differently, and why. Write "None" if nothing changed.

## Known issues

- Links to open bugs, for example [B0001](../../bugs/B0001-short-name.md). Write "None" if there are none.

## Measurements

| What | Platform | Result |
|---|---|---|
| Measurement name | Windows / Linux / macOS | Number and unit |

## Follow-up

- Work that this milestone found but did not do, and the milestone or bug it now belongs to.
